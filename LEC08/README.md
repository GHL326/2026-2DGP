# Drill #8 기사 애니메이션 뷰어

프로젝트 루트에서 실행:

```powershell
python -m pip install -r LEC08/requirements.txt
python LEC08/animation_viewer.py
```

Python 3.9 이상을 사용한다. ESC 또는 창 닫기로 종료한다.
이미지 경로는 소스 파일 위치를 기준으로 하므로 다른 작업 폴더에서도 실행할 수 있다.

## 구현 내용

- 대기 40장 → 걷기 20장 → 달리기 20장 → 검 공격 14장 → 회전 공격 16장.
- 각 동작을 5회 반복한 뒤 마지막 프레임에서 1초 정지한다.
- 회전 공격까지 마치면 다시 대기로 돌아가며 전체 순서를 무한 반복한다.
- 기존 900×700 화면, 중앙 재생, 진행 막대 및 상태 표시를 유지한다.
- 660×545 원본 PNG에서 만든 시트를 1.35배로 표시한다.
  가장 작은 프레임도 높이 352.35픽셀로 화면 높이의 절반 이상이다.
- 모든 동작에서 동일한 확대율과 수평 중앙·바닥 기준선을 사용한다.
- 현재 동작, 반복 횟수, 프레임 번호, 재생 속도와 정지 시간을 표시한다.
- 정지 중에도 입력을 처리해 바로 종료할 수 있다.

## 가산점 구현 — 제출 시 함께 언급

1. **서로 다른 프레임 크기 지원:** `knight_atlas.png`는 투명 여백을 제거해
   각 프레임의 너비와 높이가 서로 다르다. `animations.json`의 개별 사각형과
   기준점으로 잘라 그리며 고정 셀 크기에 의존하지 않는다.
2. **동작마다 다른 프레임 수 지원:** 40·20·20·14·16장을 사용한다.
   각 배열 길이와 FPS로 프레임 전환, 5회 반복 및 정지 시점을 계산한다.

## 파일과 원본

실행에는 `animation_viewer.py`, `animations.json`, `knight_atlas.png`가 필요하다.
`knight_source.zip`은 고해상도 원본 프레임이며 실행 시 압축을 풀 필요가 없다.
출처와 CC0 라이선스는 [ASSETS.md](ASSETS.md)와 [ASSET_LICENSE.txt](ASSET_LICENSE.txt)에 기록했다.

시트를 재생성할 때만 pygame을 추가로 설치한다:

```powershell
python -m pip install pygame
python LEC08/build_atlas.py
```


가변 크기·개수, 확대 크기와 화면 경계를 확인했다.
