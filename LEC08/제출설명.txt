Drill #8. 기사 애니메이션 뷰어

실행 파일: LEC08/animation_viewer.py
실행 방법 (Python 3.9 이상):
  python -m pip install -r LEC08/requirements.txt
  python LEC08/animation_viewer.py
종료: ESC 또는 창 닫기

구현 사항
- 고해상도 기사 스프라이트로 대기, 걷기, 달리기, 검 공격, 회전 공격 5종 구현.
- 원본 프레임 660×545, 가변 크기 시트 4096×3037, 총 110프레임.
- 900×700 화면 중앙에서 1.35배로 표시하며 모든 프레임 높이가 화면 절반 이상.
- 각 애니메이션을 5회 반복한 뒤 마지막 프레임에서 1초 정지.
- 모든 애니메이션을 순서대로 무한 반복.

가산점 구현 사항
1. 서로 다른 프레임 크기 지원:
   knight_atlas.png의 가변 크기 프레임을 animations.json의 개별 좌표와 기준점으로 표시.
2. 서로 다른 애니메이션 프레임 수 지원:
   대기 40장, 걷기 20장, 달리기 20장, 검 공격 14장, 회전 공격 16장.
   각 동작의 실제 프레임 수와 FPS로 반복 및 정지 시점을 계산.

스프라이트: akylrum의 Knight, Princess and Dragon 2 (CC0).
출처: https://opengameart.org/content/knight-princess-and-dragon-2
검증: 자동 테스트 6개 통과, 110프레임 실제 렌더링 및 종료 동작 확인.
커밋: 기사 자료를 사용하는 기능별 20개.
