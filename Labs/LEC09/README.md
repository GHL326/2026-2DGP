# 소닉 애니메이션 뷰어

`prd.md`에 따라 구현한 `pico2d` 자동 애니메이션 뷰어다.

## 실행

Python과 `pico2d`가 설치된 환경에서 저장소 루트 기준으로 실행한다.

```powershell
python Labs/LEC09/sonic_animation_viwer.py
```

VS Code에서 해당 파일을 열어 Python 파일 실행 버튼으로 실행해도 된다. 이미지는 소스 위치에서 찾으므로 터미널의 현재 폴더와 무관하게 실행할 수 있다. `ESC` 또는 창 닫기로 종료한다.

## 구현 결과

| 항목 | 결과 |
| --- | --- |
| 캔버스 | 1200×800 픽셀 |
| 재생 대상 | 16개 동작, 76개 프레임 |
| 재생 속도 | 초당 10프레임, 경과 시간 기반 |
| 확대 | 공통 10배, 원본 비율 유지, 최근접 보간 |
| 배치 | 가로 중앙, 공통 하단 기준선과 시트 내부 높이 차이 유지 |
| 순서 | 동작별 5회 재생 → 마지막 프레임에서 1초 대기 → 다음 동작 |
| 전체 순환 | 54초, 마지막 동작 이후 처음부터 무한 반복 |
| 오류 처리 | 이미지 누락·로드 실패 시 경로 안내 및 캔버스 정리 |

동작 순서는 대기, 올려다보기, 웅크리기, 몸 말기, 걷기, 달리기, 구르기, 공 모양, 회전, 대시, 빠른 대시, 공중 회전, 피격, 제동, 놀람, 서기다. 원본 시트에 동작명이 없어 표시된 자세를 기준으로 분류했다. 제목·제작자 서명·하단 장식 캐릭터는 소닉 동작 프레임에서 제외했다.

## 실행 및 검증 기록

2026-10-05, Windows / Python 3.13 / 설치된 `pico2d` 환경에서 확인했다.

| 단계 | 확인 결과 |
| --- | --- |
| 데이터 분석 | 16개 동작·76개 프레임 정의, 범위 및 중복 검사 통과 |
| 창과 이미지 | 실제 1200×800 창 생성, 다른 작업 폴더에서 이미지 로드 성공 |
| 화면 표시 | 실제 렌더러 화면 캡처 확인, 모든 프레임이 여백 안에 들어옴 |
| 프레임 검수 | 전체 프레임을 펼쳐 확인하고 인접 프레임 혼입 수정 |
| 픽셀 검사 | 소닉 동작 영역의 불투명 픽셀 누락 0개, 중복 0개 |
| 반복 경계 | 모든 동작이 정확히 5회 재생하고 마지막 프레임을 유지함 |
| 대기와 전환 | 0.999초에는 대기 유지, 1초에 다음 동작 진입 및 카운터 초기화 |
| 시간 처리 | 작은 시간 간격과 큰 시간 간격 모두 두 번의 전체 순환 결과 일치 |
| 실제 연속 실행 | 전체 두 바퀴 완료, 32번의 대기 시간을 측정해 1초 대비 ±0.15초 이내 확인 |
| 종료 | 실제 SDL 창 닫기와 대기 중 ESC 이벤트로 정상 종료 |
| 오류 | 이미지 누락 시 경로가 포함된 오류와 정상 자원 정리 확인 |

최종 데이터에서는 초기 경계의 누락 픽셀과 인접 프레임 조각을 모두 수정했다. 실시간 순환 검증 후 프레임 경계를 보정했으며, 보정된 데이터로 픽셀·화면 범위·반복 경계·대기 중 종료 검사를 다시 통과했다.

## 개발 이력

`lec09-animation-viewer` 브랜치에서 기능을 단계별로 구현·확인했다. 이번 개발 커밋은 이 실행 안내 문서까지 총 **22개**이며 모두 한글 메시지로 작성했다. 구현 소스는 요구한 이름의 Python 파일 하나로 유지한다.
